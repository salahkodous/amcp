# Code of Conduct

AMCP follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1: be welcoming, be respectful, assume good faith, focus on what is best
for the protocol and its community.

## Enforcement

Violations (harassment, trolling, insulting/derogatory comments, publishing
others' private information, or other conduct unbecoming in a shared
technical space) may result in warnings, temporary bans, or permanent removal
at the maintainers' discretion.

Report incidents privately to the repository owners (see commit history for
contacts) rather than opening public issues. Reports are handled
confidentially; reporters will receive a response within 7 days.

## Scope

This applies to all project spaces (repository, issues, pull requests,
discussions) and to public representation of the project. The protocol's own
rules still apply to technical disputes: argue from fixtures, vectors, and
the spec — seniority never outranks a failing conformance run.
